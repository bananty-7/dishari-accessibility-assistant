# Synthetic examples

These samples contain no real medical or personal information.

- `english-note.png` — printed English OCR smoke test.
- `bangla-note.png` — printed Bengali OCR smoke test.
- `medicine-label.png` — fabricated label for reading text only, not a prescription.
- `document.pdf` — two-page text PDF example.

Ground truth for the Bengali sample:

```text
আজ একটি সুন্দর দিন।
দিশারী বাংলা লেখা পড়ে।
```

The browser smoke script can recreate PNG samples. OCR errors on synthetic samples are useful debugging evidence, not a representative accuracy benchmark.
